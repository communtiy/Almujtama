نسخة عرض مؤقتة لمنصة المجتمع - GitHub Pages

طريقة النشر:
1) ارفع جميع الملفات الموجودة داخل هذا المجلد مباشرة إلى جذر مستودع GitHub (وليس داخل مجلد فرعي).
2) تأكد أن ملف index.html ظاهر في الصفحة الرئيسية للمستودع.
3) من Settings > Pages اختر Deploy from a branch.
4) اختر branch: main والمجلد: /(root) ثم Save.
5) انتظر دقيقة أو دقيقتين ثم افتح رابط GitHub Pages.

مهم: هذه نسخة عرض مؤقتة وليست قاعدة بيانات مركزية. البيانات تحفظ محلياً في متصفح كل جهاز.
