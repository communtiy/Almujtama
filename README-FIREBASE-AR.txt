منصة المجتمع — الإصدار 187 / v127 — نسخة Firebase Hosting
==========================================================

هذه الحزمة تم تجهيزها من:
187-AlMujtama-v127-ACCOUNTING-ANNUAL-TABLE-CLEAN-HEADER.zip

طريقة النشر السريعة على Windows:
1) ثبّت Node.js إذا لم يكن موجودًا.
2) افتح موجه الأوامر واكتب:
   npm install -g firebase-tools
3) سجّل الدخول:
   firebase login
4) أنشئ مشروعًا في Firebase Console أو استخدم مشروعك الحالي.
5) شغّل الملف:
   deploy-firebase.cmd
6) أدخل Firebase Project ID عند الطلب.

أو يدويًا من داخل مجلد الحزمة:
   firebase deploy --only hosting --project YOUR_FIREBASE_PROJECT_ID

مهم بخصوص البيانات:
- هذه النسخة تحافظ على سلوك التطبيق المكتبي قدر الإمكان، لكن داخل المتصفح.
- بيانات المنصة تُحفظ محليًا في IndexedDB داخل نفس المتصفح/الجهاز.
- الصور والفيديو والوثائق المرفوعة تُحفظ ضمن بيانات المتصفح لهذه النسخة.
- Firebase Hosting وحده هو استضافة ملفات الموقع، ولا يحول قاعدة البيانات تلقائيًا إلى قاعدة مركزية مشتركة بين جميع المستخدمين.
- إذا أردت أن يشاهد جميع الأعضاء نفس البيانات من أجهزة مختلفة، فالمرحلة التالية هي ربط الواجهة بـ Cloud Firestore وFirebase Storage وFirebase Authentication.
